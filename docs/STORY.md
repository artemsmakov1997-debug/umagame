# Игровой сценарий: Ума против инфошума

Юрий Шмаков — журналист, хозяин Умы и рассказчик. Реплики — художественный игровой текст, без записанной озвучки. Используется согласованный первый портрет.

Ума ищет Источник шума. Юрий слышит её, но не знает, где находится. Монстры захватывают устройства. Четыре журнала постепенно раскрывают человеческие решения, породившие угрозу.

Пробуждение: 0–1,4 с — сон; 1,4–2,9 с — зевание; 2,9–4,2 с — удивление. Экраны заражаются последовательно. Игра и обратный отсчёт ещё не идут. Затем две короткие реплики и передача управления.

Все разговоры останавливают симуляцию. Esc открывает меню с сохранением страницы. Финальная причина показывается после победы над боссом, затем связь возвращается в редакцию.

## Четыре записи

- **Автопубликация**: Публикация без проверки включена вручную.
- **Клики**: В отчётах точность уступила просмотрам.
- **Проверки**: Проверку фактов отключили ради скорости.
- **Реакции**: Тревожные заголовки усиливали ради отклика.
