# Сценарий: Ума против инфошума

В окне рассказчика: «Юрий», подпись «редактор», две кнопки «Далее» и «Пропустить». Заголовки ниже служат навигацией по документу и в игре не показываются. Реплики — художественный игровой текст.

Ума просыпается в тихой комнате и учится ходить, прыгать, подниматься по лестнице. Врагов и обратного отсчёта здесь нет. Затем она ищет Инфошум через шесть боевых локаций.

## Записи расследования

- **Автопубликация**: Публикация без проверки включена вручную.
- **Клики**: В отчётах точность уступила просмотрам.
- **Проверки**: Проверку фактов отключили ради скорости.
- **Рассылка**: Непроверенные сообщения рассылали всем устройствам.
- **Реакции**: Тревожные заголовки усиливали ради отклика.
