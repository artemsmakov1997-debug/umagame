# История 0.15.0

Ума ищет источник шума. Юрий не знает, где оказался, и помогает по связи.
Промежуточные реплики доступны только через необязательные блокноты.
Все способности доступны сразу; новые виды врагов появляются по очереди.

## Финал: четыре слайда

1. **УМА ПОБЕДИЛА** — Инфошум рассеивается. Шум, рождённый гонкой за просмотрами, теряет силу.

2. **ПОСЛЕДНИЙ ВИХРЬ** — Портал затягивает монстров. Редакция снова свободна.

3. **ВОЗВРАЩЕНИЕ ДОМОЙ** — Ума возвращается в редакцию. За столом её ждёт Юрий.

4. **ТЕПЕРЬ МЫ ВМЕСТЕ** — Юрий обнимает Уму. «Спасибо. Теперь наш черёд — отвечать за слова».

После четвёртого слайда появляется цель проекта, счёт и три действия:
МЕДИА.СТРАЖ, начало заново, главное меню.

«Мы сделали игру, чтобы учиться замечать манипуляции, проверять источники и ценить ответственную журналистику.»
