# История кампании 0.14.0

Ума ищет источник шума. Юрий слышен по связи, но не понимает, где оказался.
Порядок: тихая комната → редакция → арена Распространителя → крыши →
арена Агитатора → студия → арена Манипулятора → измерение → Инфошум.

Вступление и финал автоматические. Остальные страницы появляются только после
подбора необязательного подсвеченного блокнота. Пропуск не блокирует прогресс.
После мини-боссов открываются три записи о человеческих решениях, породивших шум.
