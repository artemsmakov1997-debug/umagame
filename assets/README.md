# Графика «УМА ПРОТИВ ИНФОШУМА»

- `menu-room.png` — чистое окружение главного меню без текста, кнопок и кошки.
- `uma-idle.png` — шесть отдельных кадров серой Умы: покой, моргание,
  облизывание, лизание лапы, умывание и возвращение к покою.
- `uma.png` — серые игровые спрайты покоя, бега, прыжка и удара.
- `monsters.png` — Кликбейт, рупор, Паникёр и прямоугольный пакетик супчика.
- `noise.png` — Инфошум, большой монстр, бумажные эффекты и настоящая рыбка.
- `library-room.png` — чистый фон библиотеки по утверждённому макету.
- `infonoise-motion.png` — шесть поз Инфошума: покой, два шага,
  подготовка броска, бросок и восстановление.
- `monster-motion.png` — по четыре позы рупора, Паникёра, Кликбейта и босса.
- `newsroom.png` — исходная редакция и окружение первой главы.
- `journey-rooms.png` — атлас 2×2: ночная улица, типография, телестудия,
  башня эфира. Четверти выбираются в `campaign-art.js`.
- `yuri-shmakov.png` — первый согласованный портрет Юрия для диалогов;
  последующий мультяшный вариант в игре не используется.
- `journalists.png` — прозрачные спрайты репортёра, редактора,
  представителя съёмочной группы и Юрия. Координаты — в `campaign-art.js`.
- `archive.png` — сохранённый рисунок старого прототипа; при старте не загружается.

Координаты исходных прямоугольников и прозрачных кадров находятся в `assets.js`.
Регистрация новых кадров и выбор поз по состоянию находятся в `monster-animation.js`.
Не меняйте атласы без проверки этих координат. Умывание использует реальные
разные позы в `menu-animation.js`, а не перемещение статичного изображения.

В игре фон приглушается отдельно от платформ. В редакции полосы столешниц
восстанавливаются из исходного рисунка; в остальных главах реальные поверхности
рисуются отдельно по `level.js`, включая ленты типографии. Коллизии и подсветка
используют одну геометрию. В меню фон остаётся насыщенным.

Press Start 2P хранится локально вместе с лицензией SIL OFL в `fonts/`.
`UmaText.ttf` — его сжатый по горизонтали вариант под новым именем, с той же
лицензией. `UmaDisplay.ttf` — собственный жирный пиксельный алфавит для крупных
заголовков. Оба файла воспроизводятся скриптом `scripts/build-fonts.py`
(Python 3 + fonttools); для запуска самой игры этот скрипт не нужен.
