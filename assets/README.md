# Игровая графика

Рисунки созданы на основе согласованного макета «Ночной смены».

- `newsroom.png` — окружение без игрового персонажа, помех, рыбок и HUD.
- `uma.png` — прозрачный атлас шести поз Умы; отдельные исходные прямоугольники
  и точки привязки находятся в `assets.js`.
- `noise.png` — прозрачный атлас ползающей и летающей помехи, большого монстра
  и рыбки. Монитор входит в окружение, а монстр рисуется отдельно.

Не заменяйте рисунки без проверки координат спрайтов и платформ: поверхности
столов и лестница в `engine.js` привязаны к окружению. Исходные PNG сохранены
без удаления деталей; при отрисовке сглаживание отключено.

Версия 0.3: `archive.png` — отдельное окружение архива с той же геометрией столов
и лестницы. Редакция и эфирная используют исходную комнату, для эфирной добавлен
цветовой эффект. Изображения рисуются в координатах трёх зон, камера показывает
только видимую часть карты. Ретрансляторы, затворы, щит и предупреждения босса —
отдельные игровые эффекты.
